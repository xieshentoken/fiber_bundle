# Fiber bundle scope

Fiber bundle manages local Markdown knowledge bases, original intake material, identity-preserving publication, MOC relationships, indexing and permission-scoped retrieval. It provides a desktop interface and local authenticated HTTP endpoints.

Extraction, optional model processing, review, publication and indexing have separate persisted states. Complete source content and image validation govern publication. Retry preserves original messages and completed results and checks policy revision, target, cancellation and publication identity.

User state, model credentials and knowledge files are configured outside the source tree.
